## [1.0.4] - 2025-11-24

### 修复
- 🐛 修复未成交订单撤单按钮不显示的问题
  - 后端改为发送英文枚举名 (status.name) 而不是中文值 (status.value)
  - 确保前端状态检查逻辑能正确匹配
  - 影响状态：SUBMITTING、NOTTRADED、PARTTRADED
  - 修复后所有可撤单状态都能正确显示按钮

### 新增
- ⚡ 部分撤单功能
  - 支持对未完全成交的订单进行部分撤单
  - 自动撤销原订单并下新订单保留指定数量
  - 在委托列表中显示"部分撤单"按钮
  - 智能判断是否可以部分撤单（剩余数量 > 1）
  - 新增 API: `POST /api/partial_cancel`

- 🎯 价格最小变动价位验证增强
  - 前端实时验证委托价格是否符合最小变动价位
  - 自动计算并提示建议价格（向上或向下取整）
  - 用户可选择修改价格或继续下单
  - 后端双重验证确保价格合规
  - 新增 API: `GET /api/contract_info/<symbol>`

### 改进
- 📝 增强下单价格验证提示，显示合约信息和建议价格
- 📝 优化委托列表操作按钮，区分"全部撤单"和"部分撤单"
- 📝 改进错误消息，更清晰地说明价格验证失败原因
- 📝 添加详细的新功能说明文档（`NEW_FEATURES_v1.0.4.md`）

### 技术细节

- 新增 `/api/partial_cancel` 后端路由

## 版本说明

### 语义化版本
- 主版本号：重大架构变更或不兼容更新
- 次版本号：新功能添加
- 修订号：Bug 修复和小改进

### 升级方法
```bash
# 更新代码
git pull origin main

# 激活虚拟环境
source venv/bin/activate  # Linux/macOS
venv\Scripts\activate     # Windows

# 更新依赖
pip install --upgrade -r requirements.txt

# 重启服务
```
